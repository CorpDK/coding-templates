# @corpdk/graphql-input-zod

Zod codegen and validation issue types for GraphQL input types (**SDK L3**).

| Entry                               | Use                                                                                      |
| ----------------------------------- | ---------------------------------------------------------------------------------------- |
| `@corpdk/graphql-input-zod`         | Validation issue types and `GraphqlInputValidationError` (parse helpers ship in SDK P1c) |
| `@corpdk/graphql-input-zod/codegen` | `emitGraphqlInputZodBlocks` (used by `dal-codegen` and future SDK engine)                |
