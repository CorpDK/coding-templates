# @corpdk/graphql-input-zod

Zod codegen and validation issue types for GraphQL input types (**SDK L3**).

| Entry                               | Use                                                                                                    |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `@corpdk/graphql-input-zod`         | `createInputParsers`, `createScalarParsers`, validation issue types, and `GraphqlInputValidationError` |
| `@corpdk/graphql-input-zod/codegen` | `emitGraphqlInputZodBlocks` (used by `dal-codegen` and `@corpdk/create-graphql-sdk`)                   |
