# @corpdk/graphql-input-zod

Zod codegen and runtime helpers for GraphQL input types (**SDK L3**).

| Entry                               | Use                                                                        |
| ----------------------------------- | -------------------------------------------------------------------------- |
| `@corpdk/graphql-input-zod`         | `createInputParsers`, `createScalarParsers`, `GraphqlInputValidationError` |
| `@corpdk/graphql-input-zod/codegen` | `emitGraphqlInputZodBlocks` (used by `dal-codegen` and future SDK engine)  |
