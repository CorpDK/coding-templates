# @corpdk/dal-core

Shared types, filter helpers, GraphQL scalars, and mutation error taxonomy for DAL-automated GraphQL data services.

Part of the [CorpDK coding-templates](https://github.com/CorpDK/coding-templates) DS automation stack. Use with `@corpdk/dal-codegen` and a Drizzle schema as the single authoring surface.

## Install

```bash
pnpm add @corpdk/dal-core
# or
npm install @corpdk/dal-core
```

Pin the same CalVer as the other DS automation packages (`@corpdk/dal-codegen`, `@corpdk/pub-sub`, `@corpdk/codegen-cli`, `@corpdk/create-ds`).
